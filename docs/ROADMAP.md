# ASTERA Roadmap

## P0 — Contest-ready prototype

- [x] Premium responsive portfolio command center
- [x] Anonymous, synthetic demonstration data
- [x] Estate switching and portfolio KPIs
- [x] Incident intake simulation using text, photo, or voice
- [x] AI-assisted triage simulation with visible human authority
- [x] Normalized vendor quote comparison
- [x] Explicit approval and dispatch state transition
- [x] Assets, vendors, audit trail, search, notifications, privacy and role panels
- [x] Original social/hero visual and metadata
- [x] Resettable golden walkthrough
- [x] Product, architecture, data, demo, build, deployment, and QA documentation
- [ ] Final cross-browser and device validation
- [ ] Contest submission and video capture

## P1 — Pilot foundation

- [ ] Authentication, MFA, organization and estate-scoped authorization
- [ ] Persistent database with row-level policies
- [ ] Secure evidence upload and retention controls
- [ ] Server-enforced approval policy and append-only audit log
- [ ] Idempotent vendor dispatch adapter
- [ ] Notification preferences and redacted delivery
- [ ] Observability, backups, restore drill, and incident runbooks
- [ ] Accessibility audit and automated end-to-end tests
- [ ] Indonesian and English localization

## P2 — Commercial differentiation

- [ ] Preventive maintenance plans derived from asset history
- [ ] Portfolio risk, spend, and vendor performance analytics
- [ ] Family-office summaries and configurable approval thresholds
- [ ] Integration SDK for property systems and trusted service partners
- [ ] Offline-first staff capture with secure synchronization
- [ ] Evidence-linked AI recommendations with evaluation suite
- [ ] Enterprise data residency and retention options

## Explicitly deferred

- autonomous payments;
- autonomous vendor choice or dispatch;
- public household profiles or vendor marketplace;
- surveillance and biometric features.
